# Animation Skills Showcase — 86 Styles

A responsive showcase webpage for all 86 animation styles in the library.
Every card shows the skill name on top and one primary still frame beneath
it, generated with that skill's own code. Clicking a card opens a modal with
the skill's description, best use cases, style, 5 extra stills and a ~10 s
demo video with voiceover.

## Voices

No ElevenLabs anywhere — no key exists and none is used. ElevenLabs
references were scrubbed out of the skill docs on 27 Nov 2026 (see the
skills' own OFFLINE.md notes). Voices are each skill's documented voice:

- **Kokoro `af_heart`** (local, via `~/.faceless-shorts/venv`) — default for
  every skill except cartoon-audio-short.
- **Channel TTS `avocado_v2:MAI_03`, speed 105** (`/opt/hatch/bin/tts speak`)
  — cartoon-audio-short only.

## Layout

- `index.html` + `styles.css` + `app.js` — the page (loads `skills.json`).
- `skills.json` — generated by `scripts/build-page.py` from
  `assets/<skill>/meta.json`.
- `assets/<skill>/` — `still-1.jpg` … `still-6.jpg` + `demo.mp4` + `meta.json`.
- `scripts/watchdog.sh` — monitors `status/<skill>.json` heartbeats, logs
  stalls to `logs/watchdog.log`, enforces the pause gate before the Sunday
  long-form render window.
- `status/` — per-skill progress JSON (heartbeat + state).
- `logs/` — watchdog log + pause flag.

## How it was built

86 skills processed in concurrent batches of 10, each skill rendered with
its own engine (stills from the skill's renderer, video from the skill's
frame pipeline, voiceover from the skill's documented voice). Every asset
was verified with ffprobe/file checks before the skill was marked done.

## Sequencing note

Showcase rendering pauses during the Sunday long-form render window
(Fri 27 Nov 07:00 → Sun 29 Nov 18:00 IST) so the long-form upload stays on
track; light work (voiceovers, page code, repo setup) continued in that
window and full rendering resumed after the Sunday upload.
